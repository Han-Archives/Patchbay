## 0. 고정한 구조

**Patchbay는 localhost 통합 관리 UI다.**

| 면 | 역할 | 구현 위치 |
| --- | --- | --- |
| 프로젝트 | 등록, 스캔, Atlas, overlay, progress | 기존 `@patchbay/core` + 콘솔 탭 |
| 흐름 | LLM 실행 그래프의 조회·현재 노드·원문/정리본 | **LangGraph 런타임** (Patchbay는 어댑터) |
| 지식 | 파일 그래프 검색·이웃 | **Neo4j** (Patchbay는 인제스트·조회 어댑터) |
| 캔버스 | 흐름/지식에서 올린 항목의 배치 | 콘솔 + `board.yaml` |

조작 면은 Cursor / Claude Code / 터미널. CLI와 MCP는 같은 Core를 본다. 파일이 진실이다. 작업장(`patchbay flow`)이 떠 있는 동안만 watch/SSE로 화면을 민다.

**v1에서 하지 않는 것:** 자작 워크플로 엔진, 벡터 임베딩 GraphRAG, React 코드 핫리로드 플러그인, 텔레그램 작업장, 파일 매개 멀티에이전트 배정, 부팅 자동 워치 데몬, Tauri/SaaS, Cursor 채팅 대체.

**이미 끝난 것 (다시 하지 않음):** PortId, 결정적 스캐너, inferred/Atlas/overlay, CLI(init, project add/new/triage, scan, atlas, patch, progress), MCP 읽기 5종, `apps/flow` 시드(Hono+Vite+xyflow), 텔레그램·assignments 제거.

각 단계: 목표, 작업(소요), 완료 조건, 의존, 만지지 않는 것.

### P0 제품 경계와 파일 계약 — 2일 — 다음 착수

| 작업 | 소요 |
| --- | --- |
| 한 줄 정의, 하지 않는 것, 4탭 IA 확정 | 0.5일 |
| 진실 파일: overlay, progress, board.yaml, inferred 소유권 | 0.5일 |
| 어댑터 계약: LangGraph URL, Neo4j bolt, SSE 이벤트, 쓰기 MCP 목록 | 1일 |

**완료 조건.** `docs/기획/Patchbay_기획_20260917b.md`(또는 당일 `a`)와 명세에 4탭·어댑터·watch 범위가 있고, v1 제외 목록이 닫혀 있다.

**만지지 않는 것.** 스캐너 재작성, 새 온톨로지 대청소.

### P5 LangGraph 어댑터 — 8일 — 4주 화 ~ 6주 월

**목표.** 실행 엔진을 새로 만들지 않는다. 로컬 LangGraph에 연결해 보여 준다. 실행 버튼이 있으면 LangGraph API로 위임한다.

| 작업 | 소요 |
| --- | --- |
| 로컬 LangGraph 연결 설정(URL). 미연결 UI | 2일 |
| 그래프 목록, thread, 현재 노드, checkpoint | 2일 |
| 흐름 탭 xyflow + 현재 노드 강조 | 2일 |
| 단계별 원문/정리본 패널 (스레드 state) | 1일 |
| 재연결, 실패 run, 빈 그래프 | 1일 |

**완료 조건.** 실행 중인 그래프가 흐름 탭에 있고, 노드를 고르면 상태와 원문/정리본을 본다.

**의존.** P1, P3. LangGraph 서버는 이 단계에서 붙인다.

**만지지 않는 것.** 자작 노드 런타임, n8n식 스케줄러, Patchbay 내부 그래프 DSL.

**열린 점 (닫힘).** 런타임은 로컬 `langgraph dev` HTTP (`PATCHBAY_LANGGRAPH_URL`, 기본 `:2024`). 채팅 트랜스크립트 자동 수집은 하지 않는다. 단계는 MCP 또는 LangGraph state로만 올라온다. 명세 4.1·3.1b.

## 4. 전체 완료 체크리스트

1. `patchbay flow`가 왼쪽 바 + 4탭 콘솔을 연다.
2. 등록 프로젝트의 Atlas와 progress가 프로젝트 탭에 있다.
3. CLI `progress write`가 떠 있는 화면을 갱신한다.
4. MCP 쓰기가 같은 화면을 갱신한다.
5. LangGraph가 켜져 있으면 흐름 탭에 현재 노드가 있다. 꺼져 있으면 단절 표시만.
6. Neo4j가 켜져 있으면 지식 탭에서 파일을 찾는다. 꺼져 있으면 단절 표시만.
7. 두 소스에서 올린 항목이 캔버스에 남는다.
8. 끝난 구간을 스킬 초안으로 남길 수 있다.
9. `pnpm test`가 기존 커널 회귀를 통과한다.
