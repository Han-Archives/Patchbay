## 한 줄

Patchbay는 **에이전트를 만들고 운영할 때 ‘지금 어디인지’와 ‘예전에 만든 에이전트·프롬프트를 다시 쓰는 것’**을 파일에 남기는 localhost 관제실이다. Hermes·텔레그램은 그 파일을 읽는 **경로**이지, 커널 안의 작업장이 아니다.

---

## 사용자가 고정한 목표

1. AI Agent를 만들고 돌릴 때 **어디까지 진행됐는지** 보이게.
2. **이전에 만든 Agent·프롬프트**를 다음 작업에서 다시 쓰게.
3. Cursor뿐 아니라 **Hermes, 텔레그램 등 여러 경로**에서 같은 기록을 쓰게.

해석 (2026-09-19 합의):

- 맞는 말: 여러 MCP **호스트**가 같은 스튜디오 파일을 보는 워크스페이스.
- 아닌 말: 여러 MCP **서버**를 통합 관리하는 허브. Patchbay는 MCP 서버 하나다 (`progress_write`, `place_on_board` 등).
- 텔레그램은 Hermes Gateway 면. `apps/flow`에 봇을 넣지 않는다.
- 커널은 결정적. 모델 루프·상시 데몬·텔레그램 작업장은 v1에서 닫음.

시안이 보여 준 다음 제품 구멍 (아직 코드 없음):

- 스캐너는 v1에서 `skill:`만 채움. `agent:` 포트는 온톨로지에만 있고 비어 있음.
- `prompt:` kind 없음. 프롬프트는 대개 `source:`.
- `progress write`는 호스트가 안 쓰면 빈 줄.
