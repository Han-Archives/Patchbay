대화창 모드 아이콘 버튼 & 모드별 전용 아이콘 시안

대화창에는 모드 · 플래닝 같은 긴 문구 대신 전용 SVG 아이콘만 깔끔하게 노출하고, 마우스를 올렸을 때(`title`)나 팝업 메뉴에서만 이름을 보여줍니다.

01 · 대화 화면 — 문구 없이 아이콘으로 표시되는 모드

하단 바 왼쪽엔 켜진 LLM + 현재 모드 아이콘 칩, 오른쪽엔 [+]와 [모드 아이콘 버튼]만 둡니다.

03 · 생성한 모드 아이콘 세트 & 표시 방식

대화창 안에서 글자를 없애고 한눈에 구분되는 16×16 선형 벡터 아이콘으로 표현합니다.

① 하단 바 오른쪽: [+] 옆 원형 [모드 아이콘 버튼] 기존 + 버튼(28×28 원형) 바로 옆에 같은 크기의 원형 모드 스위치 아이콘 버튼을 둡니다. 모드가 켜지면 버튼 배경색이 그 모드의 색으로 바뀌고 해당 모드 아이콘이 그려집니다.
② 하단 바 왼쪽: 켜진 LLM 칩 옆에 [현재 모드 아이콘 칩] 선택된 모드가 있으면 하단 LLM 칩 옆(구분선 뒤)에 해당 모드 아이콘 배지가 함께 놓여, 문구 줄 없이도 지금 어떤 모드인지 즉시 보입니다.
③ 대화 말풍선: [나] 옆에 작은 모드 아이콘 배지 보낸 메시지 머리에도 글자 태그 대신 20×20 모드 아이콘 배지만 붙이고, 마우스를 올리면 모드 이름이 툴팁으로 나옵니다.
