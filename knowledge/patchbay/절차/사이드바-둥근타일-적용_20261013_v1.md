# 사이드바 둥근 타일 적용

요청: 아이콘 4안 중 둥근 타입 선택.

시안 02를 제품 사이드바에 적용했다. 공통 SidebarIcon 컴포넌트로 메인, 아키텍처, 폴더, 기획, 지식 그래프, 문서 호출, 로그, 추가 기능, 대화, 프로젝트 추가를 SVG로 통일했다. 타일은 40px, 모서리는 12px, 아이콘은 22px와 2.2px 선으로 맞췄다. 대화 아이콘의 이름은 접근성 이름과 툴팁으로 제공한다. 선택·메뉴 펼침·키보드 포커스를 표시한다.

검증: Flow 형 검사 및 빌드 통과. Chrome에서 SVG 11개와 타일 스타일 확인, 추가 메뉴 열기와 Escape 닫기, 대화 토글, 390px 모바일 페이지 가로 넘침 없음 확인. 브라우저 검증은 모의 API를 사용했다.
