# 프로젝트 LLM 실행 불빛 — 2026-10-13 v1

## 요구

프로젝트에서 LLM이 일하는 동안 왼쪽 프로젝트 타일 오른쪽 아래의 동그란 불빛이 켜졌다 꺼졌다 하게 한다.

## 반영

- 대화방 답변, 설계 상담, 테스트 실행의 메모리 상태를 프로젝트별로 합쳐 `GET /api/running`에서 제공한다.
- 화면은 3초마다 실행 중 프로젝트를 확인하고 해당 프로젝트의 기존 상태 점 자리에 주황색 불빛을 표시한다.
- 움직임 줄이기 설정에서는 깜빡임 없이 켜진 상태로 두며, 조회 응답은 캐시하지 않는다.

## 확인

- 대화방·상담·테스트 실행 시험 49개 통과. 세 경로 모두 실행 중 표시와 종료 뒤 해제를 확인했다.
- Flow 형 검사, 화면 빌드, 서버 빌드 통과.
- 아키텍처 JSON 읽기 통과.
- 전체 시험 386개 중 382개 통과. 파일 감시 한도 `EMFILE`로 기존 감시·SSE 시험 4개가 시간 초과 실패했다.
