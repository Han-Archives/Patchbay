# 흐름도 세부 작업표 4안 · 2026-10-15

사용자 요청: 흐름도의 큰 칸(설계 · 구현 · 테스트 · 검토)을 누르면 아래에 그 단계의 작업 사항이 표로 나오고, 작업을 누르면 더 세부적인 항목이 아래로 펼쳐진다. 세부 항목은 사용자가 + / − 로 넣고 빼거나 LLM이 Plan한 내용이 들어가 있어 무엇을 할지 파악하게 한다. 세부 항목 옆 ▶ 를 누르면 옆 할일 목록에 올라간다. 이를 분석해 4가지 버전으로 디자인.

상태: 승인 대기. 독립 HTML 시안이며 제품 코드는 바꾸지 않았다. 예시 데이터만 쓴다. 앞선 [세부TASK-주간표5안](세부TASK-주간표5안_20261015_v1.md)을 이어받는다.

## 네 버전 공통 동작

- 흐름도 칸 클릭 → 아래 표가 그 단계 작업으로 바뀐다. 칸에 작업 수 · 세부 완료 수 · 진척 막대.
- 작업 클릭 → 그 행 아래로 세부 항목 펼침 / 접힘.
- 세부 항목: 출처 칩(LLM 계획 · 직접 추가), 체크(끝냄), ▶(할일로), −(빼기), 맨 아래 + 세부 항목 추가.
- ▶ 한 항목은 「할일에 있음 ✓」로 바뀌어 중복 등록을 막는다. 할일에서 × 로 빼면 다시 ▶ 할 수 있다. 체크와 할일 등록은 서로 독립.

## 버전별 차이

| 안 | 모양 | 특징 |
| --- | --- | --- |
| 1 | 트리 표 | 작업 행 아래로 세부가 들여쓴 줄로 붙는다. 가장 단순 |
| 2 | 펼침 상세 | 상세 칸을 「LLM 계획」 · 「직접 추가」 두 칸으로 나눔. 「모두 할일로 ▶」 |
| 3 | 아웃라이너 | 표 머리 없는 토글 목록. LLM 새 계획은 점선 「제안」 → 수락해야 정식 항목. 「LLM에게 계획 요청」 |
| 4 | 주간표형 | 접힌 행에 세부 진척 · 다음 할 일 · 할일에 올린 수. 펼치면 작은 표 |

## 구현 때 정할 것

- 세부 항목 저장 자리 (현재 `SubStep`은 `label · title · state`뿐 — 세부 항목 목록 · 출처 · 할일 연결이 없다)
- LLM Plan이 세부 항목을 언제 채우는가 (단계 진입 시 자동 / 요청 버튼)
- ▶ 로 올린 항목과 기존 할일(`todos`)의 연결 — 할일에서 완료하면 세부 항목 체크도 따라갈지
