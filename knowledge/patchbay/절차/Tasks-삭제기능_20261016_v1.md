# Tasks 메뉴 삭제 기능

작성일: 2026-10-16.

## 요청과 반영

Tasks의 `…` 메뉴에서 완료 처리 대신 삭제를 제공한다. 완료는 실제 수행한 작업의 기록이므로 목록에서 제거하려는 의도와 구분한다.

- 메뉴를 `삭제`로 변경하고 API의 `delete` 동작을 연결했다.
- 일반 할일은 목록에서 제거하고 Log에는 삭제 사건을 남긴다. 완료 시각과 완료 이력을 새로 만들지 않는다.
- 자동 추천 항목은 `deletedAt`과 비활성 표시를 저장해 다음 동기화에도 다시 나타나지 않는다.
- 연결된 대화는 보존한다. 실행 중이거나 이미 완료된 항목의 삭제는 거부한다.

## 검증

루트 TypeScript 빌드와 Flow 형검사·클라이언트·서버 빌드 통과. 할일 변경·프로젝트 변경 API 11개와 커널 할일 저장·Log 15개 시험 통과. 실제 삭제 API, 완료 이력 미생성, 대화 보존, 자동 추천 재등장 방지, 실행 중 삭제 차단을 확인했다.
