# 콘솔 대화창 「+」 정가운데 모달 창 전환 · 첨부 대기(Stage) 개선 (2026-10-31)

## 요청

1. 콘솔 대화창의 `+` 버튼을 눌렀을 때 기존 220px 팝오버 메뉴가 너무 좁아 선택하기 힘들므로, **화면 정가운데에 넓은 모달 창**이 뜨고 거기서 선택할 수 있게 바꾼다.
2. 기존 기능들(문서·사진, 프로젝트 파일, 규칙·스킬, 링크, 참여 LLM 선택, 모드 선택)도 다른 도구(ChatGPT · Claude · Cursor)에서 쓰는 일반적인 방법을 확인해 그에 맞춰 개선한다.

사용자 선택:
- **모달 적용 범위**: 대화 입력칸 아래 `첨부(+)`뿐만 아니라 아래 `LLM 추가(+)`, `모드`, 그리고 LLM 역할 설정의 `역할에 붙이기(+)`까지 모두 정가운데 모달 창으로 변경.
- **첨부 후 전송 방식**: 모달에서 파일·사진·링크·규칙/스킬을 고르면 바로 대화방으로 전송하지 않고, **입력창 위 「첨부 대기 칩(미리보기 · 개별 삭제 가능)」**에 먼저 담아 두었다가 내 메시지와 함께 `Send` / `Record`로 한 번에 전송.

## 확인한 일반적인 UX 패턴과 개선점

| 기존 문제점 | 일반적인 방법 (ChatGPT · Claude · Cursor) | 이번 반영 내용 |
| --- | --- | --- |
| 220×280px 팝오버 안에서 하위 목록이 열려 긴 파일 경로나 스킬 설명이 `...`로 잘림 | 화면 정중앙 모달(`dialog.showModal()`) + 상단 탭 분리 | 680~740px 폭의 정가운데 모달(`RoomCenterDialog`)과 4개 탭(`문서 · 사진` / `프로젝트 파일` / `규칙 · 스킬` / `웹 링크`)으로 분리 |
| 사진이나 프로젝트 파일을 고르는 즉시 메시지가 바로 전송되어 내 질문/지시와 한 메시지로 묶어 보낼 수 없음 | **Stage before Send** — 첨부 항목을 입력창 위 칩(썸네일·배지·삭제 `×`)에 먼저 담고 질문과 함께 전송 | `staged` 대기열 도입, 입력창 위 `.room-staged-row` 칩 표시, `buildComposedMessage()`로 전송 시 규칙·스킬 지시와 첨부 본문·질문을 하나로 결합 |
| 파일 업로드가 버튼 클릭 1개뿐이고 다중 선택·붙여넣기가 안 됨 | 드래그 앤 드롭 영역(Dropzone) + 다중 파일 선택 + 입력창 클립보드 이미지 붙여넣기(`Ctrl/⌘+V`) | 드래그 앤 드롭 업로드 영역, `<input multiple>`, `textarea` 클립보드 이미지 붙여넣기 추가 |
| 프로젝트 파일은 경로 한 줄만 보여 동명 파일 구분이나 내용 확인이 어려움 | 파일명 강조 + 폴더 경로 분리 + 다중 체크박스 선택 + **우측 내용/이미지 미리보기** | 파일명/폴더 분리 표시, 파일명 우선 검색(`filterProjectFiles`), 다중 선택 후 일괄 담기, 우측 실시간 미리보기 패널 제공 |
| 규칙·스킬은 이름만 보이고 `title` 툴팁에 마우스를 올려야만 한 줄 설명을 볼 수 있음 | 카드형 목록에 배지(`규칙`/`스킬`, `항상 적용`, `공용`)와 한 줄 설명을 바로 노출 + 종류 필터 | 카드형 리스트에 설명·배지 상시 표시, `전체 / 규칙 / 스킬` 필터 알약과 이름·설명 통합 검색(`filterRulesAndSkills`) 제공 |
| `LLM 추가(+)`와 `모드` 팝오버가 좁아 Agent의 모델/강도/역할이나 모드의 규약을 볼 수 없음 | 검색 가능한 중앙 모달에서 Agent 역할·모델·강도 배지, 모드의 권한·참여 LLM·규약 미리보기를 함께 표시 | `LLM 추가` 모달(검색·활성 인원·역할 설명 표시) 및 `모드` 모달(검색·모드 해제·참여 LLM·규약 2줄 미리보기)로 전환 |

## 고친 파일

- `app/apps/flow/src/roomComposer.ts`: 첨부 대기 항목(`StagedAttachment`) 생성, 메시지 합성(`buildComposedMessage`), 프로젝트 파일 및 규칙·스킬 검색/필터 순수 함수 분리.
- `app/apps/flow/src/RoomPanel.tsx`: `RoomCenterDialog` 모달 컴포넌트 추가, `첨부(+)` · `LLM 추가(+)` · `모드` · `역할에 붙이기(+)`를 정가운데 모달로 전환, 입력창 상단 첨부 대기 칩 및 클립보드 이미지 붙여넣기 구현.
- `app/apps/flow/src/console.css`: `.room-center-modal`, `.room-modal-tabs`, `.room-dropzone`, `.room-file-picker-split`, `.room-staged-row` 등 모달 및 첨부 칩 스타일 추가.
- `app/apps/flow/src/roomComposer.test.ts`: 첨부 대기 합성, 초기 렌더링, 파일/규칙/스킬 검색·필터 단위 시험 6건 추가.
