# Tasks 완료 여백과 구분선 정렬

작성일: 2026-10-16.

## 반영

- Tasks의 완료된 할일 머리 위 여백을 8px에서 12px로 4px 늘렸다.
- 왼쪽 레일의 도구 아이콘 위 구분선을 Workflow와 Review 등 세부 작업 사이 구분선과 같은 높이에 맞췄다.
- DashboardPane이 구분선 위치를 ResizeObserver로 읽어 셸의 CSS 변수에 전달한다. 데스크톱 레일은 프로젝트·구분선·도구·하단 상태 영역으로 배치하며, 프로젝트와 도구가 많으면 각각 내부에서 스크롤한다.
- 개요나 다른 화면으로 이동하면 기존 레일 배치로 돌아간다. 모바일 탐색은 기존 배치를 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 1440×900·1512×1150·1280×800·1200×720·1024×768에서 Review 선택 전후 두 구분선 높이가 일치하고 메인 스크롤·아이콘/하단 상태 겹침이 없음을 확인했다. 완료 머리 위 여백은 12px다.

프로젝트 19개 조건에서 목록 내부 스크롤과 추가 기능 메뉴 접근, 개요 이동 시 정렬 변수 정리와 복귀, 모바일 가로 넘침 없음을 확인했다.
