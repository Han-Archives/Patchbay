# History와 캘린더 하단 정렬

작성일: 2026-10-15.

## 반영

사용자 요청에 따라 History와 캘린더를 옆 채팅창 하단까지 늘렸다. 데스크톱의 메인 아래 여백을 채팅창과 동일하게 넓은 화면 24px·1250px 이하 20px로 맞췄다. 아래 카드 높이는 기존 244px에서 각각 252px·256px로 늘리고, 위쪽 흐름도·할일 높이와 위치는 유지한다. 날짜 격자는 늘어난 높이를 채우고 History는 기존 내부 스크롤을 사용한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 임시 데이터에서 다섯 해상도의 History·캘린더 하단이 채팅창과 일치함을 확인했다. 위쪽 카드의 기존 높이 유지, 메인 가로·세로 스크롤 없음, 4·5·6주 달 잘림 없음, 날짜 필터·History 최소 3건 표시, 모바일 가로 넘침 없음도 확인했다.

| 1280×800 | 252px | 776px |
| 1200×720 | 256px | 700px |
