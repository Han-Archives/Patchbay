# 사이드바 메인 아이콘 정리

요청: 프로젝트 목록 위·아래에 중복된 네 칸 아이콘 중 위쪽을 빼고, 아래 도구 영역을 구분선으로 나누며 메인 화면 아이콘을 집 모양으로 바꾼다.

상단 대시보드 버튼을 제거했다. 프로젝트 목록과 아래 도구 사이에는 데스크톱 가로선·모바일 세로선을 두고, 아래 메인 화면 버튼은 집 모양 SVG로 교체했다. 이동 대상과 접근성 이름은 그대로 유지했다.

검증: Flow 형 검사 통과. 전체 시험 최초 실행은 파일 감시 한도(`EMFILE`)로 4건 실패·390건 통과했고, 실패한 감시 관련 41건을 단일 워커로 다시 실행해 모두 통과했다. Flow 프로덕션 빌드 통과.
