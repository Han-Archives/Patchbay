## R1.3 「스크롤 없는 한 화면」 실측

Chrome으로 콘솔(4318)의 대시보드를 쓰기 요청을 막은 채 열었다.

| 화면 | 바깥 스크롤 | 잘린 칸(고치기 전) | 고친 뒤 |
| --- | --- | --- | --- |
| 1920×1080 | 없음 | 없음 | 없음 |
| 1512×982 | 없음 | Tasks | 없음 |
| 1440×900 | 없음 | Tasks | 없음 |
| 1280×800 | 없음 | Tasks | 없음 |
| 1024×768 | 없음 | Workflow · Tasks | Workflow |

Tasks의 완료 목록이 212px로 고정돼 칸 바닥 밖으로 9~63px 밀려 잘렸다. `console.css`에 같은 규칙이 다섯 번 겹쳐 있어 실제로 이기는 마지막 규칙만 「최대 212px, 최소 68px, 줄어듦」으로 고쳤다. 완료 바와 옆 작업 표의 위치는 고치기 전후가 같다. 1024×768에서는 Workflow 칸이 좁아 흐름도가 읽기 어렵다 — 고치지 않고 남긴다.
