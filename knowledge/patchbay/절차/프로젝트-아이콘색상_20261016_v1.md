# 프로젝트 아이콘 색상과 첫 글자

작성일: 2026-10-16.

## 반영

- 왼쪽 바의 프로젝트 아이콘에 파스텔 배경색을 적용했다. 프로젝트 식별자(alias)로 팔레트 색상을 정해 이름 변경·목록 순서 변경·새로고침에도 색이 유지된다.
- 두 글자 대신 이름의 첫 글자만 표시한다. 앞뒤 공백은 제외하고 한글·영문·결합 이모지를 처리한다. 빈 이름은 물음표로 표시한다.
- 선택된 프로젝트의 테두리, 실제 실행 중 표시, 전체 이름 툴팁과 접근성 이름을 유지한다. 새 프로젝트 추가 버튼은 기존 표시를 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드, workspaceView 시험 18개 통과. Chrome 임시 목록에서 한 글자·색상 적용, 같은 첫 글자를 가진 두 표본의 색상 구분, 이름·순서 변경 후 색 유지, 선택 테두리·실행 표시, 데스크톱·모바일 가로 넘침 없음을 확인했다.
