# R7.2a 수행 중 연관 중지 · 2026-10-21

## 반영

- 승인 실행 프롬프트에 현재 보류한 할일의 ID와 제목을 전달한다.
- 수행 중 보류한 할일의 결정이 새로 필요해지면 LLM은 즉시 `stopped`와 해당 ID·이유를 반환한다.
- 호스트는 실제 보류 상태인 ID만 받아 현재 할일을 `중지됨`으로 보존하고, 관계없는 다음 할일은 계속 실행할 수 있게 한다.
