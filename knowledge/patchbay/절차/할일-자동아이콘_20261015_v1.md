# 할일 자동 아이콘과 목록 높이 조정

작성일: 2026-10-15.

사용자 요청: 할일 제목 옆 자동 아이콘 → 할일 선택 → 하단 실행. 기존 목록의 보라색 준비 칸 제거, 목록 높이를 조금 축소.

## 변경

- `TodoPreparationControls`를 할일 헤더의 제목 바로 옆으로 옮기고, 순환 화살표와 번개 모양 자동 아이콘으로 표시한다. 접근 가능한 이름은 ‘자동 업무 수행’이다.
- 누르면 최대 5개 할일과 주 담당을 선택하는 창을 연다. 창을 여는 것만으로 모델을 호출하지 않으며, 하단 ‘실행’을 눌러야 기존 순차 준비 API를 호출한다.
- 목록 안의 보라색 준비 패널을 제거했다. 최근 준비 상태·연결 대화·중지는 자동 아이콘으로 연 창 안에서 확인한다. 준비 중에는 아이콘 색상과 툴팁으로 상태를 표시한다.
- 미완료 목록 최대 높이를 480px → 420px로 줄였다. 항목 수와 보관 기준은 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 임시 작업 공간에서 헤더 아이콘 위치, 보라색 칸 제거, 420px 높이, 아이콘을 눌렀을 때 미실행, 최대 5개 선택과 하단 실행, 준비 결과와 승인 완료, 새로고침 및 모바일 가로 넘침을 확인했다. 모델 응답은 테스트 대역을 사용했다.
