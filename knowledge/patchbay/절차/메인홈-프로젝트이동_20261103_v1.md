# 메인화면 프로젝트 클릭 이동

작성일: 2026-11-03

- 요청: 메인화면에서 프로젝트를 누르면 해당 프로젝트 창으로 이동한다.
- 원인: 기존에는 프로젝트 이름 버튼만 `onOpenProject`에 연결되어 카드 표지·요약·빈 공간을 클릭하면 반응하지 않았다.
- 변경: `WorkspaceHome.tsx`에서 카드 전체를 덮는 기본 버튼을 배치했다. 갤러리와 목록 모두 기존 `App.pickProject(alias)`로 해당 프로젝트 대시보드를 연다. `workspaceHome.css`에서 즐겨찾기·결과물 보기·앱 실행을 위에 배치해 별도 동작을 유지하고 키보드 포커스를 카드 안에 표시한다.
- 검증: Flow 타입 검사·제품 빌드 통과. 임시 작업 공간의 Chrome에서 카드 표지·요약 클릭과 서로 다른 프로젝트 선택, 즐겨찾기, 결과물 대화상자, 앱 새 탭, 실행 주소 없는 비활성 버튼, 목록 행, Enter, 390px 모바일 이동 확인. 실제 4318 메인화면 카드 이동까지 총 10묶음 통과. 검증 중 브라우저 오류와 변경 API 요청은 0건.
- 반영: 기존 서버가 빌드된 정적 파일을 제공하므로 서버 재시작 없이 적용했다. 이미 열린 브라우저는 새로고침하면 적용된다. 아키텍처 원본 JSON과 설명 문서에 이동 범위를 맞췄다.
