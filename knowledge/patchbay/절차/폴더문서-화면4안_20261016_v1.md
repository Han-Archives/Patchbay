## 네 안 공통

- 루트부터 이 프로젝트 폴더만 보인다. `node_modules` · `.git` · 루트 `workspace` · `archive`는 숨기고, `.claude` · `.cursor`는 보인다. 폴더가 먼저, 그다음 이름 순이다.
- 폴더를 누르면 설명(그 폴더 README 첫 단락, 없으면 「설명 없음」) · 하위 수 · 최근 수정 시각, 파일을 누르면 미리보기가 뜬다. 마크다운은 렌더링하고 나머지는 고정폭 글꼴로 보인다.
- 「편집」을 누르면 저장 · 취소 버튼이 뜬다. 조회 전용 접속에서는 편집 버튼이 없다.
- 🔒 비밀 파일은 열지 않는다. 이미지 · 바이너리는 「미리보기 없음」으로 둔다.
- 밖에서 바뀐 파일은 저장할 때 막고 「바뀐 내용 다시 읽기 / 내 것으로 저장」을 고르게 한다.

## 3안을 고르면 정할 것

- 막대의 범위. 시안은 아래 전체 파일을 센다. 큰 폴더에서도 빠르려면 「바로 아래 항목만」 세거나 스캔 결과를 쓴다. 스캔 결과를 쓰면 스캔 없는 프로젝트에서는 막대가 빈다.
- 종류 나누기(문서 · 코드 · 설정 · LLM 설정)를 확장자와 `.claude` · `.cursor` 경로로만 정할지.
- 콘솔 규칙상 색은 상태에만 쓴다. 그래서 막대는 회색 농도와 빗금으로 나눴다. 구별이 충분한지 화면에서 확인한다.

검증: 가짜 DOM으로 스크립트를 돌려 네 안이 오류 없이 그려지는지 확인했다. 조회 전용에서는 편집 버튼이 없고, 화면 어디에도 `workspace` · `node_modules`가 나오지 않았다. 헤드리스 Chrome 캡처는 실행 승인이 나지 않아 찍지 못했다. 브라우저로 직접 열어 확인한다.
