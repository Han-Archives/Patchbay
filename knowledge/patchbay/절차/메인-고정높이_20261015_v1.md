# 메인 화면 고정 높이

작성일: 2026-10-15.

## 요청과 반영

메인 대시보드에서 전체 스크롤 없이 흐름도·할일·History·캘린더를 볼 수 있도록 높이를 고정했다.

- 데스크톱 대시보드는 화면 높이 안의 고정 격자로 표시하고 바깥 스크롤을 제거한다. 개요 문서와 좁은 화면의 기존 탐색은 유지한다.
- 흐름도와 할일은 같은 고정 높이이며 기존 할일 높이인 618px를 상한으로 한다. 화면이 낮으면 하단 카드가 화면 안에 들어오도록 둘을 함께 줄인다. 항목 수가 바뀌어도 높이는 변하지 않는다.
- 할일·완료 목록의 ‘없습니다’ 문구를 제거하고 빈 영역으로 유지한다. 긴 할일과 흐름도 세부 작업은 카드 안에서 스크롤한다.
- History와 캘린더는 각각 244px. 하단은 화면 아래에서 32px 떨어뜨려 왼쪽 LG·N4 사이에 맞춘다. History 내용만 내부에서 스크롤한다.
- 프로젝트 이름과 개요/대시보드 버튼이 있는 상단 바는 기존 59px의 0.9배인 53.1px로 줄였다.
- 고정 History에서 기록 추가 폼이 잘리지 않도록 별도 대화상자로 표시한다. 날짜·영역 태그·내용 저장 기능은 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 임시 데이터에서 아래 해상도별 메인 영역의 가로·세로 스크롤 없음, 두 상단 카드 높이 일치, 하단 244px, LG/N4 정렬과 상단 바 53.1px를 확인했다.

| 화면 | 흐름도·할일 높이 | History·캘린더 높이 |
| --- | --- | --- |
| 1440 × 900 | 524.9px | 244px |
| 1512 × 1150 | 618px | 244px |
| 1280 × 800 | 424.9px | 244px |
| 1200 × 720 | 344.9px | 244px |
| 1024 × 768 | 392.9px | 244px |

6주짜리 달력이 잘리지 않는지, 별도 창에서 기록을 저장할 수 있는지, 빈 할일로 바꿔도 높이가 유지되고 빈 안내 문구가 없는지 확인했다. 빈 목록 검증에서는 임시 화면의 자동 할일 제안을 차단해 실제 빈 조건을 만들었다.
