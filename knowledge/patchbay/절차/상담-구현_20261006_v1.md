## 걸으며 찾아 고친 것

1. **시간 초과가 안 끝났다.** 호스트 CLI를 끝내도 자식 프로세스가 출력 파이프를 쥐고 있어 「끝남」이 오지 않았다(가짜 실행 파일 시험에서 잡힘). 프로세스 묶음으로 띄우고 묶음째 끝낸다.
2. 상담자 답의 `**굵게**`가 별표째 보였다 → 굵게만 그린다.
3. 초안이 없을 때 패널이 「아직: 없음 — PRD로 확인할 차례」라고 했다 → 「일곱 주제 모두」.
4. 폰에서 설계 탭 넷이 찌그러졌다 → 가로로 밀고 설명 줄은 숨긴다.
5. 패널의 요구사항 번호가 줄바꿈에 밀렸다 · 「예시 6/3」 → 줄을 블록으로, 「6개 — 충분」.
6. 채택한 뒤에도 채택 버튼이 다시 켜졌다(초안 = 승인본) → 같은 판이면 끄고 「이미 채택한 판과 같다」.

## 판단

- **채택 문은 화면에서만 닫는다.** 화면 채택(`adoptIrView`)은 PRD 11절 「맞아요」 + 검사 통과. CLI `ir adopt`는 경고만 — 묻지 않는 명령이라서. 명세 §14.2를 그렇게 고쳤다.
- **호스트를 바꾸면 세션은 새로, 상담은 이어서.** 새 호스트 첫 턴에 지난 대화를 넣는다. Codex 세션 id는 첫 턴이 끝나야 알아 그때 `meta`를 한 줄 더 붙인다.
- **보내기는 202로 바로 돌려준다.** 호스트 한 턴이 수십 초라 화면은 `consult` 이벤트 + 3초 다시 읽기로 결과를 받는다.
