바뀐 점 (태그 색 구분 안 기준)

  1. 상태 열항목명 바로 옆에 대기 중 · 진행 중 · 완료. 작업 행은 세부 항목을 모아 보인다. 하나라도 진행 중이면 진행 중, 모두 끝나면 완료. 글자 자리는 고정, 색으로 구분 — 대기 회색 · 진행 보라 · 완료 초록.
  2. 앞 표시 정리항목명 앞 점과 맨 앞 ▸ 를 없앴다. ▸ 자리에 번호를 넣었다. 작업은 01, 세부는 1.1. 행을 누르면 펼치고 접는다.
  3. 실행 중 불빛LLM이 실제로 실행 중인 세부 항목만 번호 앞 동그라미가 보라색으로 깜빡인다. 작업 행은 깜빡이지 않는다. 불빛 자리는 미리 비워 두어 이름 · 상태 칸이 밀리지 않는다. 동작 줄이기 설정에서는 켜져만 있다.
  4. 실행 칸글자 없이 아이콘만 — ▶ 할일로 · 할일에 있음(누르면 빼기) · ✓ 완료 · − 빼기. 뜻은 마우스를 올리면 보인다.
  5. 그대로인 것흐름도, 태그 색과 왼쪽 색 띠(표 아래 태그 설명 줄은 뺐다), ▶ 할일로 · − 빼기 · + 추가, 7글자 뒤 「...」.
