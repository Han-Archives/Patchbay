# 대화방 — 여러 모델이 한 기록 · 2026-10-08

| 항목 | 값 |
| --- | --- |
| 요구 | 오른쪽 대화창에서 Codex · Claude · Grok · 오픈소스 LLM이 한 대화방으로 이어 말하고, 방을 새로 만들고, 이전 방 기록을 다시 연다 |
| 전제 | API 키를 받지 않는다. 콘솔이 이미 로그인된 CLI를 부른다. 커널은 모델을 부르지 않는다 |
| 검증 | 대화방 시험 5 (기록 2 + 호스트 3, 가짜 실행기). 콘솔 타입 검사와 빌드 통과. 전체 스위트는 이번 작업에서 다시 세지 않았다 |

## 구조

오른쪽 대화 칸은 두 모드다.

- **모델** (기본). 사람이 이번 말을 누구에게 보낼지 고른다. 답은 같은 방 기록에 남고, 다음 모델은 그 기록을 통째로 읽고 이어서 답한다.
- **그래프**. 2026-10-05의 LangGraph 대화 그대로다. 폴더가 달라서 모델 방 기록이 그래프 재개로 들어가지 않는다.

| 무엇 | 어디 |
| --- | --- |
| 기록 `rooms/<id>.jsonl` — user(`to`) · speaker · system | `dev/packages/core/src/rooms/` |
| CLI 호출. Claude `claude -p`, Codex `codex exec --sandbox read-only`, Grok `grok --no-auto-update -p --output-format json` (Grok Build, 답 필드 `text`), 로컬 `ollama run` | `dev/apps/flow/src/roomHost.ts` |
| 화면 — 방 고르기, 모델 고르기, 보내기 | `RoomPanel.tsx`. `App.tsx` 머리의 모델 / 그래프 |

상담(`consult/`)은 1 설계 초안을 쓴다. 대화방은 초안을 쓰지 않고, 호스트 세션(`--resume`)도 이어 가지 않는다. Claude의 세션에는 Grok의 말이 없기 때문이다.

## 아직 실측하지 않은 것

Grok과 ollama의 인자 형식은 이 컴퓨터에서 확인하지 않았다. 실행 파일이 없으면 그 모델은 고를 수 없고, 화면이 「없음」으로 보여 준다. Claude · Codex 인자도 상담과 달리 세션을 잇지 않는다.
