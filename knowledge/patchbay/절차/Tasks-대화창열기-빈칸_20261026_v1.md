# Tasks 「대화창 열기」가 빈 칸으로 열리던 것 (2026-10-26)

## 증상

Tasks 할일의 「…」 → 「대화창 열기」를 누르면 주소는 `#room/<프로젝트>/<대화 ID>`로 바뀌는데 오른쪽 대화창이 비어 있었다(제목 · 메시지 · 목록 없음). 새 대화를 만드는 「대화창 만들기」는 열렸다.

## 원인

`RoomPanel`은 링크로 방이 들어오면(`openRoom`) 먼저 보던 방과 목록을 비우고(`setRoom(null)` · `setRooms([])`) 방 ID를 넣는다. 열려던 방이 **이미 보던 방**(마지막으로 연 방)이면 ID가 그대로라, ID가 바뀔 때만 도는 읽기가 다시 돌지 않아 비운 칸이 그대로 남았다. 새로 만든 방은 ID가 바뀌어 읽혔다.

## 고침

같은 효과 안에서 방 · 목록을 비울 때 기존 다시 읽기 신호(`tick`)도 올린다 — `app/apps/flow/src/RoomPanel.tsx`.
