## 1. 화면 배치 및 구성 (사용자 선택 반영)

1. **왼쪽 하단 레일(`.rail-foot`) 상시 미니 체력바 여러 줄**
   - 64px 폭 레일 하단에서 `대화` 버튼과 `LG`·`N4` 점 사이에 공급자별(`CL` · `CX`) 미니 체력바 묶음을 상시 노출한다.
   - 각 줄은 위쪽에 **약자(`CL` / `CX`) + 남은 체력**, 아래쪽에 **4칸 눈금이 들어간 가로 체력바(HP 게이지)**를 둔다.
   - 레일 대표 체력은 **5시간 세션 체력**과 **7일 주간 체력** 중 더 낮은 비율(`min(sessionPct, weeklyPct)`)을 보여준다.
   - 상태 색은 Patchbay 다크 토큰을 그대로 쓴다:
     - **31% ~ 100% (양호)**: 보라색 (`var(--ok)`, `#a78bfa`)
     - **1% ~ 30% (주의)**: 주황색 (`var(--warn)`, `#e3a35a`)
     - **0% (고갈 / 한도 도달)**: 빨간색 (`var(--bad)`, `#ef7b6e`)

2. **왼쪽 하단 상세 창 (클릭 시 열리는 팝오버)**
   - 레일 하단의 미니 체력바 묶음을 클릭하면 오른쪽 옆(`left: calc(100% + 12px); bottom: 8px`)에 **LLM 구독 체력** 상세 창이 열린다.
   - 상단에서 `[체력 상태 | 체력통 설정]` 두 탭을 전환한다.
   - **체력 상태 탭**:
     - 공급자별 카드로 **5시간 세션 체력**(10칸 눈금 게이지, 남은 비율, 누적/기준 토큰, 자연 회복까지 남은 시간)과 **7일 주간 체력**(10칸 눈금 게이지, 남은 비율, 누적/기준 토큰, 주간 리셋 시각)을 함께 표시한다.
     - 호스트 CLI가 한도 도달 문구(`usage limit`, `session limit`, `weekly limit`, `resets ...`)를 반환한 경우 즉시 **HP 0% · 고갈** 배지와 **자동 회복 시각 안내 + `[수동 회복]` 버튼**을 표시한다.
   - **체력통 설정 탭**:
     - 구독 등급 프리셋(`Pro / Plus`, `Max 5x`, `Max 20x`, `직접 입력`)을 고르거나 공급자별 5시간 세션·7일 주간 기준 토큰 수를 직접 수정할 수 있다.
     - 설정값과 한도 도달 상태는 작업 공간(`llm-quota.json`)에 저장한다.

## 2. 구현 및 검증 결과

1. **커널 (`@patchbay/core`)**
   - `app/packages/core/src/studio/llmQuotaStore.ts`: `readLlmQuotaConfig` · `updateLlmQuotaConfig` · `loadLlmQuotaSnapshot` · `detectQuotaLimitError` · `recordLlmQuotaExhausted` · `clearLlmQuotaExhausted` 구현.
   - Patchbay 작업 공간(`rooms/` · `consult/`)뿐 아니라 호스트의 로컬 CLI 세션(`~/.claude/projects/**/*.jsonl`, `~/.codex/sessions/**/*.jsonl`)을 함께 스캔해 터미널·IDE에서 쓴 토큰까지 합산.
   - 캐시 재사용 입력 토큰(`cached_input_tokens`, `cache_read_input_tokens`)은 구독 한도 차감에서 제외하고, Claude `quotaLimits`(`resetsAt`) 리셋 이력과 OpenAI 서버 `rate_limits`(`primary`/`secondary` `used_percent` · `resets_at`)가 있으면 우선 반영.
   - `app/packages/core/src/consult/types.ts`: 상담(`consult`) 호스트 메시지에 선택적 `usage: { input, output }` 필드 추가.
   - `app/packages/core/src/studio/llmQuotaStore.test.ts`: 5시간/7일 창 토큰 합산, 호스트 `~/.claude`·`~/.codex` 세션 합산 및 캐시 토큰 제외 / `rate_limits` 우선 적용, 한도 초과 0% 잠금 및 수동 회복, 프리셋/커스텀 체력통 저장 단위 시험 통과 (4건).
2. **콘솔 서버 및 화면 (`@patchbay/flow`)**
   - `app/apps/flow/src/consultHost.ts` · `roomHost.ts`: 상담 JSON 출력에서 `usage` 토큰을 함께 기록하고, `roomHost`는 `cached_input_tokens`를 제외한 순수 입력 토큰만 저장. 상담·대화방 호출이 구독 한도 초과로 실패하면 `recordLlmQuotaExhausted`로 즉시 0% 잠금을 기록.
   - `app/apps/flow/src/server.ts`: `GET /api/llm-quota` · `POST /api/llm-quota`(프리셋/커스텀 체력통 변경 및 `action: "recover"` 수동 회복) 라우트 추가 및 `server.test.ts` 통과.
   - `app/apps/flow/src/LlmHealthRail.tsx` · `App.tsx` · `console.css`: 왼쪽 하단 `.rail-foot` 내 상시 미니 체력바 묶음 및 상세 팝오버 창 연결. 서버 `rate_limits` 기준 잔여량과 누적 토큰이 함께 있을 때 `(서버 한도)`로 명확히 표기.
