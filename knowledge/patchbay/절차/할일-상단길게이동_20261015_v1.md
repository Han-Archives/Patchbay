# 할일 상단 정리와 길게 눌러 이동

작성일: 2026-10-15.

## 반영

- 영문 네트워크 오류 대신 한국어 연결 안내를 표시하고 정상 조회 후 안내를 지운다. 이전 오류가 남아 있던 문제도 고쳤다.
- 제목 옆 날짜를 진행할 할일 총 건수로 바꿨다. 완료·비활성 항목은 총 건수에 포함하지 않는다.
- 자동 아이콘을 오른쪽으로 옮기고 자동·추가·찾기 순서로 배치했다. 찾기는 기존 할일 기록 검색 창을 연다. 하단 기록 보기와 안내 줄은 제거했다.
- 목록 앞 이동 손잡이를 제거했다. 항목을 420ms 길게 누르면 끌어 이동하고 놓을 때 기존 move API로 저장한다. 이동 위치 표시와 목록 가장자리 자동 스크롤을 제공한다.
- 짧게 누르기는 내용 펼치기, 짧게 밀기는 일반 스크롤이다. Escape·영역 밖에서 놓기는 취소한다. 실행 중 항목·읽기 권한 사용자는 이동할 수 없다. 메뉴의 위·아래 이동과 제목에서 Alt+↑/↓도 제공한다.
- 상단 및 목록의 날짜를 제거했다. 보관 기록 검색 창에는 등록일·완료 일시를 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드와 todoActions 시험 5개 통과. Chrome 임시 데이터로 상단 건수·아이콘 순서, 추가 후 건수, 빈 목록 0건과 기록 접근, 기록 검색, 오류 복구를 확인했다.

마우스 및 실제 브라우저 터치 이벤트로 길게 눌러 순서 변경·새로고침 후 보존, 짧은 클릭·터치 스크롤, Escape·영역 밖 놓기 취소, 키보드 이동, 읽기 권한·실행 중 이동 제한을 검증했다. 목록 가장자리 자동 스크롤로 끝에 도달해 마지막 순서가 저장되는 것도 확인했다. 1440×900·1280×800·1024×768에서 메인 스크롤 없음을, 390×844에서 가로 넘침 없음을 확인했다. 실제 사용자 할일과 LLM 실행은 시작하지 않았다.
