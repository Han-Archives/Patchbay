# 상담 — 등록 LLM 호출 · 2026-10-17

요청: 「상담 역할을 LLM이 진행하는데 그걸 내가 등록한 LLM을 호출해서 쓸 수 있게 기능을 변경해줘. 상담창 맨위 오른쪽편에 호출할 수 있게 해줘」.

## 바뀐 것

- 상담 창 머리 줄 오른쪽 끝에 등록 LLM 고르기(`AgentPicker`)를 두었다. 버튼에는 지금 LLM의 아이콘 · 이름 · 모델이 보이고, 누르면 Agents 목록(`agents.json`)이 열린다. 아이콘은 대화방과 같은 `chipFace` · `chipStyle`.
- 예전의 호스트 고르기와 모델 입력칸은 이 고르기로 대신했다.
- 보내면 `POST /api/consult/send`에 `agentId`를 넘긴다. 서버가 그 Agent의 공급자 · 모델 · effort로 Claude Code(`--effort`) 또는 Codex(`-c model_reasoning_effort`)를 부른다. `agentId` 없이 `host` · `model`을 보내는 예전 길도 그대로 된다.
- 상담 기록 `meta`에 `agentId` · `agentName` · `effort`를, 답 줄에 `agentName`을 남긴다. 화면은 「상담자 · 수리 · claude-opus-5-5 · n초」로 보인다. 이어 가는 상담을 열면 그 상담의 LLM이 다시 골라진다. LLM을 바꾸면 새 세션으로 가고 `host-switch` 줄에 이름이 남는다.
- 처음 열면 지금 부를 수 있는 첫 등록 LLM이 골라진다.

## 정한 것

- **상담을 맡을 수 있는 것은 Claude Code · Codex Agent뿐이다.** 상담자는 초안을 Patchbay MCP `consult_update`로 쓴다. Grok · 로컬(LM Studio) 호출은 MCP를 붙이지 못한다. 그래서 목록에는 보이되 「상담 불가(초안을 쓰는 도구 없음)」로 막았고, 서버도 400으로 거절한다.
- **Agent의 역할 글은 쓰지 않는다.** 상담의 역할은 상담 안내(`buildConsultBrief`)가 정한다. 등록 LLM에서 가져오는 것은 공급자 · 모델 · effort · 이름 · 아이콘이다.
