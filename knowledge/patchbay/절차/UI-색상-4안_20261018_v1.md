# UI 색상 4안 · 2026-10-18

요청: 「이 프로젝트의 ui 색상을 한번 변경할 지 고려중인데 가독성이 좋은 대표적인 색상으로 디자인을 짜줘. 이때 색상은 최대 3개 이내로 써야되고 백그라운드는 다크랑 화이트 이렇게 나눠서 4개 이내로 산출물 디자인 안을 그려줘」.

시안: [index.html](UI-색상-4안_20261018_v1/index.html). 지금 콘솔 구성(레일 · Workflow 단계 · 작업 표 · Tasks · 대화 칸)을 줄여 그리고, 안마다 다크와 화이트를 나란히 둔다. 구현 전 제안이다.

## 정한 해석

- 「색 3개」는 강조 색 수다. 바탕 · 카드 · 선 · 글자 같은 회색 단계는 세지 않는다.
- 같은 색을 다크에서는 밝게, 화이트에서는 진하게 쓴다. 둘 다 글자 대비 4.5:1(WCAG AA 본문) 이상이다.
- 색은 역할에만 쓴다. 포인트(누를 것 · 통과) · 지금 할 일 · 실패의 셋이다(결정 2026-10-05 「색은 상태에만」 유지). 칩에는 글자(✓ 완료 · ● 진행 중 · ✕ 실패)를 같이 둔다.

회색 단계: 다크 `#121212 · #1a1a1a · #222222 · #333333`, 글자 `#f2f2f2`, 보조 `#9a9a9a`(5.65). 화이트 `#f3f3f5 · #ffffff · #f7f7f9 · #e0e0e5`, 글자 `#1b1b1f`, 보조 `#62626b`(5.45).
