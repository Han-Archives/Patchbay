# 할일 변경을 반영한 메인 화면 시안

사용자 요청: 할일 칸의 기존 시안 방향을 확인하고, 변경된 상황을 고려한 메인 화면 전체를 보여 달라는 요청.

산출물: [전체 메인 화면](할일-메인화면_20261014_v1/desktop.png), [인터랙티브 HTML](할일-메인화면_20261014_v1/index.html).

기존 메인 화면의 왼쪽 도구, 중앙 대시보드, 오른쪽 프로젝트 대화 배치를 기준으로 구성했다. 할일에는 등록 날짜, 추가 버튼, 원형 실행 표시, 순서 변경 손잡이, 전용 대화 메뉴, 한 행 높이의 완료 목록을 적용했다. 선택한 할일의 전용 대화는 오른쪽 프로젝트 대화 영역에서 표시한다. 기록 보기는 별도 대화상자로 열어 메인에서 테이블이 늘어나지 않게 구성했다.

예시 데이터로 구성한 독립 시안이며 제품 코드는 변경하지 않았다. 실제 구현 전 전체 화면 검토 단계다. 브라우저에서 추가, 키보드 순서 변경, 할일 대화 연결, 완료 처리, 좁은 화면 넘침 및 런타임 오류를 확인했다.
