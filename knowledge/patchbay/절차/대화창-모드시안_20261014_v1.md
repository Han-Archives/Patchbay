## 디자인 결정 (사용자 선택 및 아이콘 전환 반영)

1. **문구 대신 전용 벡터 아이콘 표시 (`Icon-First`)**: 대화창 안에서 `모드 · 플래닝`이나 `현재 모드: 플래닝` 같은 텍스트 줄을 모두 없애고 16×16 선형 SVG 아이콘으로만 표시한다.
   - **하단 오른쪽**: 기존 `+` 버튼(28×28 원형) 옆에 같은 크기의 원형 **모드 아이콘 버튼**을 둔다. 모드가 선택되지 않았을 때는 슬라이더 아이콘, 선택되었을 때는 그 모드의 배경색과 전용 아이콘이 들어간다.
   - **하단 왼쪽**: 켜진 LLM 칩 옆(구분선 뒤)에 **현재 선택된 모드 아이콘 칩**을 나란히 두어 텍스트 없이도 현재 모드를 한눈에 확인하고 클릭 시 바로 해제할 수 있게 한다.
   - **메시지 머리**: `나` 옆에도 글자 태그 대신 20×20 모드 아이콘 배지만 붙이고, 마우스를 올리면(`title`) 모드 이름이 툴팁으로 보인다.
2. **생성한 기본 모드 아이콘 세트**:
   - **토의**: 겹쳐진 두 말풍선
   - **보고서 작성**: 문서와 본문 줄
   - **플래닝**: 분기 경로와 노드 그래프
   - **디자인**: 레이아웃 격자 프레임
   - **스터디**: 펼쳐진 책
   - **코딩**: 코드 꺾쇠(`</>`)
   - **디버그·검토**: 탐색 돋보기와 과녁
3. **모드 선택 후 보내기 (`select_then_send`) & LLM 조합 선택 연결 (`optional_preset`)**: 팝업에서 모드를 클릭하면 방의 현재 모드로 지정(`RoomMeta.modeId`)되며, 연결된 LLM 조합이 있으면 자동으로 켜진다.
4. **상단 카드 탭 전환 (`tab_switch`)**: `LlmFace` 상단 고정 카드에서 `[LLM 호출 | 모드 추가]` 탭을 전환하며, `모드 추가` 탭에 **모드 아이콘 모양 선택 격자**를 함께 둔다.
