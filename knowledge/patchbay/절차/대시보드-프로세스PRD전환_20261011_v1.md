# 프로세스와 PRD 전환


## 2026-10-11 정돈된 프로세스와 PRD 전환
요청: 작아진 아키텍처 영역 확대, 캔버스 대신 정돈된 프로세스, 같은 칸에서 PRD 버튼으로 문서 보기.
반영: SystemArchitecturePanel을 HTML/CSS의 상담·설계 / 구현·테스트 / 공급자·조회 세 영역과 단계·인계·기록·피드백으로 재구성. 메인 영역 최대 높이 520px. 아키텍처·PRD 전환 버튼 및 ProjectPrdPreview(실제 /api/prd 초안 문서, 절 선택, 설계 검토 이동)를 추가. 전체 현황 스크롤은 없고 PRD 내용 영역만 필요한 경우 스크롤한다. 왼쪽 아이콘과 확장된 대화창, 실제 진행·테스트 이력 Log도 유지.
검증: Flow 빌드 통과. Chrome에서 캔버스 제거·PRD 내용/탭 전환·Log 및 아이콘 전환 확인. 1600×1000, 1366×768, 820×900, 390×844에서 본문 넘침 없음.
