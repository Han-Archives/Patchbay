# 새 대화 LLM 직접 선택

- 요구: 새 대화에 모든 LLM이 자동 설정되지 않고 사람이 직접 선택한다.
- 원인: 할일 대화 생성 시 `todoActions.ts`에서 등록 Agent 전체를 참여자로 복사했다.
- 수정: 새 대화는 `members: []`로 생성한다. 등록 목록과 기존 대화의 선택은 유지한다. 하단 LLM 추가 메뉴에서 선택할 수 있다.
- 검증: todoActions·roomHost 시험 25개 통과. 등록 LLM이 있어도 새 대화가 비어 있고 선택 후 다시 열어도 유지됨을 검증했다. Flow 형검사·빌드 통과.
