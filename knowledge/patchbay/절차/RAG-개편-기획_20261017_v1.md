## Claude 검토와 보완

실제 Claude CLI `claude-opus-5-5`에 고정 기획 입력본만 전달했다. 2026-10-17 08:53:23~08:56:17 KST, 정상 종료. safe-mode·도구 없음·strict MCP·세션 미보존·임시 cwd로 실행했으며 Claude의 코드·추가 링크 열람은 없었다.

원안 판정은 **조건부 가능**. 다음을 반영했다.

1. 첫 완성은 P1 본문 검색 + P2 출처 답변으로 축소. 의미 검색 P3, 보관·구조화 대화 첨부 P4, 승인 관계 보강 P5.
2. 공유 source의 retrieval/graph 사용 목적과 철회 생애, 전체 해시 개정 감지·명시적 재등록을 정의.
3. 정본 인용을 불변 원문 버전·문자 범위·해시로 고정하고 모델의 문장별 quote를 검사.
4. 평문 대화 복사를 제외하고 구조화 첨부·대상 모델 전달 게이트·원격 유출 카나리아 시험을 후속 진입 조건으로 지정.
5. 파생 세대 정리, 본문 없는 전송 감사, 모델 미적재 시 단어 검색, 한국어 검색 시작안과 평가 표본 한계를 명시.

Claude의 로컬 모델 우선 지정은 사용자의 모델 직접 선택을 보존하기 위해 채택하지 않았다. graph=false source의 seq를 건너뛰는 방식은 현행 증가 커서 계약과 맞지 않아 정상 no-op 반영으로 구체화했다. 원문·보관본 즉시 삭제는 보존 규칙과 달라 별도 정책으로 분리했다. 수정된 기획을 Claude가 재승인한 것으로 표현하지 않는다.
