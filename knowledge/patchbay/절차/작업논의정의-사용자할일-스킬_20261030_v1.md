# 작업 논의 대상 정의 · 사용자 할 일 안내 공용 스킬 (2026-10-30)

## 요청

LLM에 무엇을 작업할지 요청할 때 **논의 대상에 대한 정의**와 **사용자가 해야 하는 일**을 명확하게 설명해 주도록 안내하는 스킬 문서를 만든다. 관련 문서를 검색하고 그를 근거로 작성한다.

사용자 선택:
1. 동작 방식: **LLM 응답 가이드** — 사용자가 작업을 요청하거나 할일 대화를 열면 LLM이 먼저 ① 논의 대상 정의 ② 사용자가 정할 일/할 일을 명확히 정리해 설명하도록 지시하는 스킬
2. 저장 범위: **작업 공간 공용 스킬 (`workspace/skills/`)** — 모든 등록 프로젝트에서 공통으로 사용

1. `knowledge/patchbay/절차/Tasks-내차례-깜빡임_20261029_v1.md` (`app/apps/flow/src/todoTurn.ts`): 사용자가 "지금 뭘 해야 하는지 모르겠다"고 한 문제를 해결한 기록. `todoTurn.ts`가 판정하는 7가지 사용자 차례(준비본 검토 · 재검토 · 준비 실패 확인 · 답 확인 · 오류 확인 · 실행 승인 · 실행 실패 확인)를 사용자 할 일 분류의 근거로 삼았다.
2. `workspace/projects/patchbay/rules/briefing.md` · `knowledge/patchbay/절차/할일순서-브리핑-대화표_20261026_v1.md`: 모든 줄을 강조하면 요점이 묻히므로 칸(`요점` · `지금 할 일` · `정하실 것` · `최근 끝낸 일`)을 나누어 사람이 정해야 할 것만 번호 목록으로 빼는 구조를 반영했다.
