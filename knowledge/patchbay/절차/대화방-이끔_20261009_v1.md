# 오른쪽 대화 — Claude가 이끌고 Codex · Grok이 맡는다 · 2026-10-09

| 항목 | 값 |
| --- | --- |
| 요구 | 프로젝트를 운영하는 대화를 오른쪽 채팅에 둔다. 이끄는 모델은 Claude, 맡은 모델은 Codex와 Grok |
| 상태 | 설계. 화면과 기록 형식은 아직 고치지 않았다 |
| 두지 않음 | 질문마다 모델을 골라 주는 라우터. 그래프 대화(`threads/`)를 이 흐름에 넣기. 1 설계 상담(`consult/`)이 초안을 쓰는 일을 여기로 가져오기 |

기획서의 「하네스」는 요구사항 설계의 연결 목록 · 검사다 (기획 20261008a §1). 이 문서는 그 말이 아니다. 여기는 **이끄는 모델**과 **맡은 모델**이다.

## 한 줄

사람은 항상 Claude에게 말한다. Claude가 Codex 또는 Grok에게 일 하나를 맡기면, 사람이 그 맡김을 확인한다. 맡은 답이 같은 기록에 붙고, Claude가 반영할 것과 버릴 것을 가려 다음 한 걸음을 말한다.

```
사람 ──말──▶ Claude
                │
                │  맡김 한 줄 (검토 또는 반박)
                ▼
         사람이 [맡긴다 | 건너뛴다]
                │
                ▼
         Codex 또는 Grok  ──답──▶ 같은 방 기록
                │
                ▼
         Claude가 가려 다음 한 걸음
                │
                ▼
              사람
```

한 사람 말에 맡김은 한 번이다. Claude가 답을 가리는 차례에서는 맡김 줄을 쓰지 않는다. Codex와 Grok은 서로 맡기지 않는다.

## 화면 (오른쪽 대화 · 모델)

그래프 탭은 그대로다. 모델 탭의 입력은 「Claude에게」만 남긴다. 매번 모델을 고르는 칸은 치운다.

Claude 답 아래에는 일이 둘만 있다.

| 단추 | 맡은 모델 | 하는 일 |
| --- | --- | --- |
| 검토 맡기기 | Codex | 기록과 코드를 읽고, 같은 내용이 맞는지 한 번 더 본다 |
| 반박 맡기기 | Grok | 방금 결론에 다른 각도로 답한다 |

Claude가 답 끝에 맡김 줄을 쓰면, 같은 카드가 먼저 뜬다. 사람이 누르기 전에는 콘솔이 맡긴 모델을 부르지 않는다.

```
맡김: codex | 이 변경이 기록과 맞는지 봐 줘
맡김: grok | 방금 결론에 다른 각도로 답해 줘
```

이 두 줄 말고는 맡김으로 읽지 않는다. 실행 파일이 없거나 로그인이 없으면 단추는 눌리지 않고, 이유를 카드에 적는다. Claude의 답은 그대로 남는다.

대화기록과 맥락 붙이기는 지금과 같다. 빈 창으로 열고, 이전 방은 옆 목록에서 연다.

## 기록

파일은 그대로 `rooms/<id>.jsonl`이다. 줄을 하나 더한다.

| 역할 | 내용 |
| --- | --- |
| `handoff` | `job`은 `review` 또는 `counter`. `speaker`는 `codex` 또는 `grok`. `reason`은 사람이 읽을 한 줄. `state`는 `proposed` · `declined` · `running` · `done` · `failed` |

사람은 `user` / `to: claude-code`만 보낸다. 맡은 답은 지금처럼 `speaker`다. 가리는 답도 Claude의 `speaker`다. 호스트 세션은 이어 가지 않는다. 매번 그 방의 기록 전체를 넘긴다. Claude의 세션에는 Codex · Grok의 말이 없기 때문이다.

## 부르는 법

콘솔만 부른다. 커널은 모델을 부르지 않는다. API 키는 받지 않는다.

| 모델 | 호출 | 경계 |
| --- | --- | --- |
| Claude | 지금 대화방의 `claude -p` | 이 칸에서는 초안 파일을 쓰지 않는다 |
| Codex | `codex exec --json --sandbox read-only` | 읽기만. 상담 MCP를 붙이지 않는다 |
| Grok | `grok --no-auto-update -p --output-format json` | 도구 자동 승인을 켜지 않는다 |

로컬 모델(ollama · LM Studio)은 이 운영 대화의 맡은 이가 아니다. 호출 코드는 남겨 두고, 이 화면의 입력에서는 뺀다.

## 하지 않음

- 맡김을 사람 확인 없이 실행하기
- 한 사람 말에 Codex와 Grok을 이어서 시키기
- 이 방에서 `ir.proposed.yaml`을 쓰기
- 그래프 재개(`threads/`)와 기록을 합치기
- 채택 · 검사를 이 대화가 대신하기. 다음 한 걸음은 말이고, 반영은 지금 있는 채택과 검사다

## 이 맥 (2026-10-09 기준)

Claude 실행 파일은 있다. Grok Build는 설치돼 있고 로그인은 아직이다. Codex 실행 파일은 없다. 없는 맡은 일은 카드에 「없음」으로 두고, Claude에게 말하는 길은 막지 않는다.
