보라색(`--ok`) 게이지. 4칸 눈금으로 대략적인 잔여량 직관 파악

고갈 / 한도 도달 (0%)
빨간색(`--bad`) `0%` 표시. CLI 한도 문구 감지 시 즉시 전환

체력(HP) 차감 및 회복 동작 원리

  1. 대표 체력 = min(5시간 세션 잔여%, 7일 주간 잔여%)
    세션 체력이 64% 남았어도 주간 체력이 28% 남았으면 레일에는 더 급한 28%(주황)를 표시합니다.
  2. Patchbay 전 경로 토큰 합산
    대화방(`rooms/*.jsonl`)과 설계 상담(`consult/*.jsonl`)에서 발생한 입력+출력 토큰을 공급자별로 실시간 합산합니다.
  3. 슬라이딩 윈도우 자연 회복
    5시간이 지난 호출 기록은 세션 창에서 빠지면서 시간이 흐르면 체력바가 자연스럽게 차오릅니다.
  4. CLI 한도 도달 즉시 0% 고정
    호스트가 `usage limit` / `weekly limit` / `resets 2pm`을 반환하면 계산값과 무관하게 즉시 0% (고갈)로 잠그고, 해제 시각이 지나면 풀립니다.

3. 「체력통 설정」 탭 전환 시 화면

구독 등급(Pro / Max 5x / Max 20x) 프리셋을 고르거나 내 체감 한도에 맞춰 최대 토큰 크기를 직접 조절합니다.
