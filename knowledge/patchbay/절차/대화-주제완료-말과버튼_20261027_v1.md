# 대화 주제 완료 — 말로 끝내기 · 「완료」 버튼 (2026-10-27)

## 요구

완료 안내(`대화-할일완료안내-다음할일_20261027_v1.md`)는 LLM이 할일을 완료로 표시할 때만 떴다. LLM 지시문이 "작업을 한 차례에만, 답변·확인만으로는 완료하지 않는다"였기 때문에 이야기만 나눈 주제는 끝나지 않았다. 사용자가 1(말로 끝내기)과 2(대화창 「완료」 버튼)를 함께 고름.

## 고침

- 말로 끝내기: LLM 지시문에 "사용자가 이 대화의 주제가 끝났다고 말하면(「끝났어」 「이건 완료」 「다음으로 넘어가자」) 작업이 없었어도 이 대화와 roomId가 같은 미완료 할일을 완료한다"를 넣음 — `roomHost.ts`. 할일 지시를 받는 방(쓰기 가능한 Claude · Codex가 있는 일반 방)에서만 통한다. 토의 같은 읽기 전용 방은 버튼으로 끝낸다.
- 「완료」 버튼: 방이 맡은 미완료 할일이 있으면 입력칸 위에 「할일 · 제목 [완료]」. 방이 맡은 할일은 「대화창 열기」로 만든 방이면 그 할일, 아니면 이 방에 연결된 미완료 할일이 하나일 때 그것. 누르면 `POST /api/room/complete` → 완료 안내 · 다음 할일 링크를 먼저 남기고 할일을 완료로 옮긴다. LLM이 답하는 중이면 막는다 — `roomHost.ts` `completeRoomTodo` · `server.ts` · `RoomPanel.tsx` · `console.css`.
- 대화 화면 데이터(`/api/room`)에 `todo { id, title }`. 할일 파일이 깨져도 대화는 열리고 버튼만 숨긴다.

## 확인

- `todoActions.test.ts` 「대화창 「완료」는 완료 안내와 다음 할일 링크를 남긴 뒤 할일을 완료로 옮긴다」 추가. flow 545 통과, 타입 검사 통과.
- 실제 콘솔 다시 빌드 · 다시 켬. 「콘솔 재시작 후 「브리핑」…」 방에 「할일 · … [완료]」가 보임(누르지 않음). 브리핑 방에는 남은 연결 할일 「Cursor 규칙 링크 걸기」가 표시된다.
- 말로 끝내기는 실제 LLM으로 확인하지 않음.
