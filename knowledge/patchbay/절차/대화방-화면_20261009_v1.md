# 대화 화면 — 2026-10-09

사용자가 준 메인 화면을 오른쪽 대화에 넣었다.

- 위는 제목과 「대화」「LLM」.
- 대화는 빈 칸, 왼쪽 더하기, 입력, 보내기, 아래 아이콘이다. 더하기에는 대화기록과 시작 말이 있다.
- LLM은 연결(실행 파일을 찾았는지, 로컬은 모델 id)과 사용량이다. 사용 가능한 LLM, 역할명, 주요 역할을 적고 켜면 대화 아래에 아이콘이 나온다.
- 패킷 숫자는 호출 결과가 `usage.input_tokens` · `output_tokens` 를 준 때만 남긴다. 없으면 「호출 결과에 양이 없다」.
- 꺼진 사람은 한 바퀴에서 빠진다.

시험: 대화방 호스트 6, 기록 4. flow 타입 검사 통과.
