# 프로젝트 이름과 폴더 함께 변경

작성일: 2026-10-16.

## 사용 방법

상단 프로젝트명을 더블클릭하거나 키보드로 선택 후 Enter를 누르면 이름 수정 창이 열린다. 새 이름을 입력하고 저장하면 등록된 실제 프로젝트 폴더의 마지막 이름도 함께 바뀐다. 수정 창에 폴더 변경 안내와 현재 경로를 표시한다. 취소·Escape는 변경하지 않는다.

프로젝트 아이콘 배경은 45%에서 25% 불투명도로 낮췄다. hover는 32%다.

## 구조

- ProjectNameEditor.tsx → POST /api/project/name `{ alias, name }` → core studioStore.renameProject().
- 표시 이름(name)과 실제 레포 폴더·등록 경로(path)를 갱신한다. 같은 폴더 내부에 별도 등록된 프로젝트의 경로도 함께 갱신한다.
- alias·작업 공간 projects/<alias>·할일·대화·보관 기록의 식별자는 유지한다. 저장 후 기존 board 이벤트와 화면 재조회로 헤더·왼쪽 아이콘을 갱신한다.
- studio.yaml은 임시 파일 작성 후 rename으로 저장하며 등록·숨김·이름 변경은 같은 파일 잠금으로 직렬화한다. 등록부 저장 실패 시 폴더를 원래 위치로 복구한다. 복구 경로까지 다른 항목이 차지했다면 덮어쓰지 않고 현재 폴더 위치를 오류로 알린다.
- 조회 전용·다른 출처 쓰기 요청, 잘못된 폴더 이름·중복 폴더·심볼릭 링크 루트, 실행 중 작업을 거절한다. 폴더 이동 중 새 쓰기 요청도 잠시 거절한다.
- 현재 실행 중인 Patchbay 또는 작업 공간을 포함하는 폴더는 이동하지 않는다. 이 폴더를 옮기면 현재 서버·작업 공간의 기준 경로가 끊어지므로 오류로 안내한다.
- 레포 내부 문서나 외부 프로그램 설정에 직접 적힌 임의의 절대 경로를 일괄 치환하지는 않는다.

## 검증

Core·Flow 빌드와 관련 33개 시험 통과. 실제 폴더·문서 보존, 중첩 등록 경로, 할일·대화 ID 유지, 잘못된 이름·충돌·실행 중·조회 권한·출처 제한, 저장 실패 복구와 복구 경로 충돌, 동시 등록/숨김, 이동 중 쓰기 제한을 확인했다.

Chrome 임시 프로젝트에서 더블클릭·키보드 편집, 실제 폴더 이동·등록부 갱신, 상단과 아이콘 갱신, 새로고침 보존, 취소·중복 오류, 25% 배경, 모바일 입력 창과 조회 전용 UI를 확인했다. 기존 4318 서버는 실행 중인 LLM 작업 없음을 확인하고 접속 설정을 유지해 재시작했다. 실제 사용자 프로젝트 이름과 폴더는 검증 중 변경하지 않았다.
