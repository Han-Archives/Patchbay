# 메인 화면·대시보드 디자인 개편

- 요청: 왼쪽에서 여는 대시보드, 오른쪽 설계–구현–운영 진행바, 지식 그래프·문서 호출 카드, 아키텍처·프로세스 배치.
- 반영: 프로젝트 선택·이름·대시보드 버튼을 기본 대시보드에 연결. 기존 여섯 항목 상단 띠를 세 단계 오른쪽 진행바로 교체. 기능 카드에 실제 잠김 사유와 진입 버튼 표시. 기존 ArchPanel을 PRD 구조로 구동. 프로세스와 최근 작업 표시. 모바일은 진행을 상단에 가로 표시.
- 검증: Flow 형검사·빌드 통과. 관련 대시보드·작업 공간 테스트 확인. 전체 시험에서 SSE progress 이벤트 시간 초과가 발견되어 별도 기록.

- 검증 확정: 관련 24개 시험 통과. 전체 376개 중 372개 통과, 파일 감시·SSE 관련 4개 실패 및 EMFILE(파일 감시 자원 한도) 발생. 브라우저 시각 검증은 수행하지 못함.
