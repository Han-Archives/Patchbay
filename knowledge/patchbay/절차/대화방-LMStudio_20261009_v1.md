# 대화방 — 로컬은 LM Studio · 2026-10-09

| 항목 | 값 |
| --- | --- |
| 요구 | 로컬 사람은 Ollama가 아니라 LM Studio로 부르고 싶다 |
| 상태 | 설계. 콘솔의 로컬 자리는 아직 `ollama run`이다 |
| 실측 | 이 맥에 `lms`가 있다 (`~/.lmstudio/bin/lms`). `127.0.0.1:1234`가 모델 목록을 준다. 메모리에 올라간 대화 모델은 `qwen2.5-14b-instruct-mlx` |

## 한 줄

로컬 사람의 이름은 LM Studio 모델 id다. 콘솔은 `lms chat -p`로 그 모델에게 이 방의 말과 역할 한 줄을 넘기고, 나온 글을 받아 방에 붙인다.

```
lms chat -p "<이 방의 말>" --system-prompt "<역할 한 줄>" <모델 id>
```

`-p`는 답을 표준 출력으로 내고 끝난다. 대화형 세션을 이어 가지 않는다. API 키는 없다. 커널은 모델을 부르지 않는다.

## 화면

사람 줄의 로컬은 모델 id로 보인다. 이 맥에서 지금 올라간 대화 모델은 `qwen2.5-14b-instruct-mlx`다. 역할은 다른 사람과 같이 한 줄이고, 「대화 시작」「토의 시작」의 바퀴에 같은 순서로 들어간다.

`lms`가 없거나 그 id가 디스크에 없으면 그 차례는 「없음」이고 다음 사람으로 간다. 서버가 꺼져 있으면 `lms`가 띄우는지는 아직 한 턴으로 확인하지 않았다. 확인 전에는 꺼져 있으면 「없음」으로 둔다.

- `127.0.0.1:1234`에 콘솔이 직접 HTTP를 보내기. 다른 사람도 실행 파일을 부르므로 로컬도 `lms`로 맞춘다
- 임베딩 모델(`text-embedding-bge-m3`)을 말하는 사람으로 부르기
