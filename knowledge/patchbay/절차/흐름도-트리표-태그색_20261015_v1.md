# 흐름도 트리표 · 태그 색 구분 · 2026-10-15

사용자 요청: [흐름도-트리표4안](흐름도-트리표4안_20261015_v1.md) 중 2안(태그 색 구분)으로 진행. 항목명 옆에 진행 중 · 대기 중 같은 상태를 넣고, 항목명 앞 동그라미와 맨 앞 ▸ 를 없애고 ▸ 는 번호로 바꾸고, LLM이 실제로 실행 중이면 그 항목명 앞에 깜빡이는 불빛으로 보이게 다시 디자인.

상태: 승인 대기. 독립 HTML 시안이며 제품 코드는 바꾸지 않았다. 예시 데이터만 쓴다.

## 표

열: 번호 · 항목명 · 상태 · 설명 · 태그 · 실행.

- 번호: 작업 01, 02 … · 세부 1.1, 1.2 …. 행 어디를 눌러도 펼치고 접는다. 펼친 작업은 번호가 보라색.
- 항목명 앞 점(LLM / 직접 추가 구분)을 없앴다 — 출처는 화면에 더 이상 보이지 않는다.
- 상태: 대기 중 · 진행 중 · 완료. 같은 너비 · 같은 자리, 색으로 구분 (대기 회색 · 진행 보라 · 완료 초록). 작업 행은 세부 항목에서 모은다 (하나라도 진행 중 → 진행 중, 모두 완료 → 완료). 완료 행은 흐리게 · 취소선.
- 실행 중 불빛: LLM이 실제로 실행 중인 세부 항목만 번호 앞 동그라미가 보라로 깜빡인다. 작업 행은 깜빡이지 않는다. 불빛 자리는 번호 칸에 미리 비워 두어 이름 · 상태 칸이 밀리지 않는다. 할일 칸의 그 항목에도 같은 불빛. 동작 줄이기 설정에서는 고정 불빛.
- 실행 칸: 글자 없이 아이콘만. 대기 ▶ · −, 할일에 올림 = 목록 아이콘(누르면 할일에서 빼기) · −, 실행 중 = 목록 아이콘만, 완료 = ✓. 뜻은 툴팁 · 스크린리더 이름으로. 작업 행 실행 칸은 비움.
- 표 아래 태그 설명 줄은 뺐다.
- 흐름도는 처음 시안 그대로 (작업 수 · 세부 완료/전체 · 막대).

시안 할일 칸의 「맨 위 할일 시작 / 실행 끝내기」는 LLM 실행을 흉내 내는 시안 전용 버튼이다. 실제 구현에서는 연결된 방의 실행 상태(할일-구현 20261014의 보라 점멸과 같은 근거)로 불빛을 켠다.

## 구현 때 정할 것

- 세부 항목의 「진행 중」을 무엇으로 판단할지 — 할일에 연결된 방의 실제 실행 상태를 그대로 쓰는 안을 권한다
- 세부 항목 저장 필드: 이름 · 설명 · 태그 · 상태 · 할일 연결

수정 (같은 날 사용자 요청): 불빛을 이름 앞 → 번호 뒤로, 태그 설명 줄 삭제, 상태 칸 밀림 보완, 실행 중 항목만 깜빡임.

수정 2 (같은 날): 상태 글자 밀림 수정 — 상태의 `run` 클래스가 실행 칸 `.run`(오른쪽 정렬) 스타일과 겹쳤던 것. 불빛을 번호 앞으로, 실행 칸 글자 제거.
