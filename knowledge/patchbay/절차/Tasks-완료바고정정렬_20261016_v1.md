# Tasks 완료 바 고정 정렬

작성일: 2026-10-16.

## 반영

사용자 요청으로 완료된 할일 바의 윗변을 옆 Workflow 작업 표의 윗변에 맞췄다. 진행할 할일 개수가 바뀌어도 완료 바는 같은 위치를 유지한다. 기존 DashboardPane의 ResizeObserver에 표·머리 높이 측정과 비동기 DOM 변경 관측을 추가했고, 표 등장 애니메이션의 이동량은 정렬 계산에서 제외한다.

완료 목록은 53px 행 두 개에 해당하는 106px 높이로 고정하고 넘치는 항목은 내부에서 스크롤한다. 진행 목록도 독립적으로 스크롤한다. 화면 높이가 낮거나 표 머리가 줄바꿈되면 Workflow 그림 높이를 줄여 완료 두 줄이 잘리지 않도록 공간을 확보한다. 모바일에서는 위아래 카드 배치와 완료 두 줄 스크롤을 적용한다.

## 검증

Flow 형검사·클라이언트·서버 빌드 통과. Chrome의 1440×900·1512×1150·1280×800·1200×720·1024×768에서 표와 완료 바의 윗변 차이 0px, 완료 목록 106px, 행 53px, 실제 스크롤과 잘림 없음을 확인했다. 설계에서 Review로 전환해도 정렬을 유지하고 390×844 모바일 가로 넘침이 없음을 확인했다. 시험은 임시 서버와 가상 할일 12개·완료 5개로 실행했다.
