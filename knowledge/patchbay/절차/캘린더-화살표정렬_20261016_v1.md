# 캘린더 화살표 중앙 정렬

작성일: 2026-10-16.

이전·다음 달 버튼의 문자 화살표를 대칭 SVG로 바꿨다. 버튼을 inline-flex로 정렬해 글꼴 기준선 영향을 없애고 가로·세로 중앙에 아이콘을 배치한다. 버튼 크기와 접근성 이름·월 이동 기능은 유지한다.

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 1440×900·1024×768·390×844에서 SVG와 실제 화살표 경로의 중심이 버튼 중심과 일치(가로·세로 차이 0px)함을 확인했다. 이전·다음 달 이동과 화면 이미지도 확인했다.
