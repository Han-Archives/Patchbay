# History 간결화

작성일: 2026-10-15.

## 반영

- History 아래 연도·월 줄을 제거하고 현재 조회 건수를 제목 옆에 표시한다. 캘린더 날짜 필터에 따라 건수도 바뀐다.
- ‘변경 내용 보기’를 제거하고 내용을 바로 표시한다. 행 여백을 줄여 고정된 244px 카드에서도 최소 3건을 볼 수 있게 했다.
- ‘+ 기록 추가’ 버튼과 입력 창을 제거했다. 기존 기록과 저장 API는 보존한다.
- 태그와 내용 사이 간격을 넓혔다. 긴 내용은 2줄, 태그는 2줄 높이로 표시하고 마우스를 올리면 전체 내용을 확인할 수 있다.
- 긴 목록은 History 내부에서 스크롤한다. 날짜 필터와 ‘Log에서 보기’는 유지한다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome에서 1440×900, 1280×800, 1512×1150, 1024×768 화면을 확인했다. 최소 3개 행 전체 표시, 내부 스크롤, 메인 전체 스크롤 없음, 제목 옆 건수, 날짜 필터 건수 갱신을 검증했다. 긴 내용 및 6개 태그 기록도 임시 데이터에서 확인했다. 실제 사용자 할일은 실행하지 않았다.
