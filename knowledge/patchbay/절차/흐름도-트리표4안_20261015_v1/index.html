흐름도 트리표 · 4가지 버전

승인 전 시안 · 예시 데이터

이번 요구사항

  1. 트리 표 · 흐름도 그대로앞 시안의 1안 트리 표를 바탕으로 한다. 흐름도 칸과 할일 칸은 바꾸지 않는다.
  2. 항목명업무 이름. 7글자를 넘으면 7글자 뒤를 「...」로 줄인다. 마우스를 올리면 전체 이름이 보인다.
  3. 설명무엇을 하는지 짧게 한 줄.
  4. 태그가장 위 분류 하나 — UI · Agent · 데이터 · 서버 · 문서. 작업 행에는 아래 세부 항목들의 태그가 모여 보인다.
  5. 실행▶ 를 누르면 오른쪽 할일 맨 아래에 올라간다. − 는 빼기, 표 맨 아래 + 는 네 칸을 그대로 입력하는 줄.

글자 수는 띄어쓰기 · 가운뎃점도 한 글자로 센다. 네 버전 모두 열 순서(항목명 · 설명 · 태그 · 실행)와 동작은 같고, 태그를 보여 주는 방식과 실행 칸의 모양이 다르다.
