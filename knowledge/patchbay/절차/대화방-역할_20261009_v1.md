# 대화방 — 사람을 부르고 역할로 시작한다 · 2026-10-09

| 항목 | 값 |
| --- | --- |
| 요구 | GPT에서 쓰는 채팅방처럼 보이되, LLM을 사람처럼 불러 역할을 텍스트로 주고, 「대화 시작」이나 「토의 시작」이라고 하면 그 상태로 진행한다 |
| 상태 | 설계. 콘솔 화면은 아직 고치지 않았다 |
| 두지 않음 | 맡김 단추 둘(검토 · 반박)로 역할을 고정하기. 시작 말 없이 모델을 부르기. 한 바퀴가 끝난 뒤 사람이 말하기 전에 다음 바퀴를 잇기 |

`대화방-이끔_20261009_v1.md`의 맡김 카드는 이 화면의 입구가 아니다. 역할은 그 사람에게 적은 글이다.

## 한 줄

방은 GPT 채팅과 같이 말풍선과 아래 입력이다. 사람은 말할 모델을 방에 불러 이름을 두고, 역할을 한 줄로 적는다. 「대화 시작」또는 「토의 시작」이 나오기 전에는 그 사람들을 부르지 않는다.

```
사람 ──부르기──▶ 방 안의 사람 (Claude · Codex · Grok)
                    │
                    │  역할은 텍스트
                    ▼
              「대화 시작」 또는 「토의 시작」
                    │
                    ▼
              부른 순서대로 한 번씩
                    │
                    ▼
              멈춤. 다음 시작 말을 기다린다
```

## 화면

왼쪽은 방 목록이다. 다음 호출은 지금 방만 읽는다. 역할도 그 방에만 있다.

가운데는 채팅이다. 입력 칸 위, 말풍선 위에 그 방의 사람이 이름과 역할로 놓인다. 「사람 부르기」로만 늘어난다. 메시지마다 모델을 고르는 칸은 없다.

| 말 | 하는 일 |
| --- | --- |
| 대화 시작 | 각 사람이 자기 역할로 주제만 답한다. 앞 사람의 결론을 받아치지 않는다 |
| 토의 시작 | 각 사람이 자기 역할로 답하고, 바로 앞 사람의 말에서 한 점을 받는다 |

둘 다 부른 순서대로 한 바퀴다. 한 사람이 끝나면 다음 사람만 부른다. 바퀴가 끝나면 입력은 다시 사람 것이다.

실행 파일이 없거나 로그인이 없으면 그 사람 차례에 「없음」만 남고, 바퀴는 다음 사람으로 간다.

## 호출

콘솔만 부른다. 커널은 모델을 부르지 않는다. API 키는 받지 않는다. 그 사람에게 넘기는 글은 이 방의 말과 그 사람의 역할 한 줄이다. 다른 사람의 세션을 이어 가지 않는다.

## 하지 않음

- 시작 말 없이 역할만 보고 모델을 부르기
- 검토 · 반박 단추로 역할을 대신하기
- 한 바퀴 안에서 같은 사람을 두 번 부르기
- 이 방이 설계 초안을 쓰기. 채택은 지금 있는 길이다
