## 배치

왼쪽은 최대 5개 할일과 묶음 진행, 가운데는 보라색으로 구분한 준비 대화와 승인 동작, 오른쪽은 산출물 미리보기·연결 관계·완료 조건이다. 모바일에서는 할일을 가로로 탐색하고 대화와 산출물을 세로로 배치한다.

## 확인할 흐름

상단에서 대상 선택 → 순차 준비 → 결과 검토 → 실행 완료 → 선행 결과 변경 상태를 전환한다. 대상 선택, 준비 시작·중지, 할일 선택, 연계 해제, 산출물 열기, 수정 요청, 보류, 개별 승인 동작을 시연한다.

디자인이 미승인 요구사항을 참조한 기본 예시에서는 ‘그대로 진행’을 누르면 선행 요구사항을 먼저 확인하도록 안내한다. 요구사항을 승인한 뒤 디자인으로 돌아와 승인하면 완료 상태로 바뀐다. 필수 선행 결과가 없는 구현·검증은 계획만 준비한다. 선행 결과 변경 화면은 재검토 필요 상태를 보여준다.

## 시안의 범위와 검증

예시 자료와 메모리 내 상태 전환을 사용한다. LLM 호출·파일 반영·실제 검증·영속 저장은 수행하지 않는다. 시나리오 전환은 전체 실행 상태를 복원하는 제품 동작이 아니라 검토용 장면 선택이다.

Chrome에서 대상 선택, 준비·중지, 선행 승인 안내, 개별 승인과 완료, 변경 상태, 모바일 가로 넘침, 런타임 오류 여부를 검증했다. 데스크톱·모바일·변경 상태 이미지를 생성했다.
