## 막힘

1단계는 화면 안에서 닫혀 있었다 — 설계 없음 → 시작 → Phase 1~9 → 판정 → 채택. 그런데 채택하면
화면이 「채택했다 — v1」 한 줄로 끝났고, 다음 걸음인 뼈대 생성은 작업 공간 「다음 할 일」이
**`patchbay ir generate` 로 만든다**고 말했다. 앞 걷기가 찾은 것과 같은 모양이다 — **보여 주기는
하고 시작하기가 없다.**

## 넣은 것

| 무엇 | 어디 |
| --- | --- |
| 2단계 한 장 (승인본 버전 · 세 파일 · 노드 집합) | `GET /api/build` · `buildView.ts` · `buildContract.ts` |
| 「뼈대 생성」 | `POST /api/build/generate` → Core `writeScaffold` |
| 구현 화면 | `BuildPane.tsx` — 뼈대 칸 · 승인본 그래프 · 아래에 실행 중 흐름 |
| 채택 뒤의 입구 | `IrPane` 채택 결과 줄에 「2 구현으로 — 뼈대 생성」 |
| 「다음 할 일」 문구 | `workspaceContract.ts` — 터미널 명령 대신 화면의 버튼을 가리킨다 |

쓰기 경로는 Core `writeScaffold` 하나다(원칙 8). 그래서 **`--force` 없음**과 「있는 파일을 덮지
않는다」(원칙 3)가 화면에서 다시 구현되지 않는다 — 두 번 눌러도 사람이 고친 `graph.ts` 가 그대로다.

## 정한 것

**화면의 생성 길은 승인본만 먹는다.** CLI에는 `ir generate --proposed` 가 있지만 버튼으로 내지
않았다. 화면에 그것까지 열면 사람이 채택을 건너뛰고 코드를 만들 수 있고, 그러면 2단계가 1단계의
산출물만 먹는다는 규칙이 화면에서만 느슨해진다.

**채택 전은 오류가 아니라 `locked` 이다.** 1단계를 아직 지나지 않은 것은 정상 상태라서, 404가
아니라 「무엇을 기다리는지」와 「1 설계 열기」를 같이 돌려준다.

**어긋남은 수가 아니라 노드로 보인다.** 2.6은 설계 화면이 쓰는 `toIrCanvas`(흐름 탭의 `layout()`
+ XYFlow)를 그대로 돌려 승인본 회로를 그리고, `graph.ts` 에 없는 노드만 점선으로 둔다. 표를 새로
만들지 않았다 — 관계가 있는 데이터는 그래프가 기본값이다(`visual-first`).

**「아직 없다」와 「어긋난다」를 합치지 않았다.** 생성 전에는 `graph` 가 빈 배열이고 화면은
「`graph.ts` 는 아직 없다」고 말한다. 같은 자리에 「승인본에만: intake, classify …」를 띄우면
고장처럼 읽힌다.

## 걸은 길 (실서버, 임시 스튜디오)

고정 자료(`valid.ir.yaml`)를 초안으로 둔 임시 레포를 등록하고 `patchbay flow` 로 걸었다.

| 걸음 | 답 |
| --- | --- |
| 채택 전 `GET /api/build` | `locked` · 「1 설계에서 초안을 채택하면 …」 |
| 채택 전 생성 시도 | 409 · 「설계가 채택되지 않았다 — 1 설계에서 채택한 뒤에 생성한다」 |
| `POST /api/ir/adopt` | v1 |
| 채택 뒤 `GET /api/build` | `ready` · 세 파일 다 없음 · `nodes.graph` 빈 배열 |
| 「뼈대 생성」 | `written: state.ts, graph.ts, evals.test.ts` · `match: true` |
| 다시 생성 | `written: []` · `skipped` 셋 · 사람이 쓴 줄 그대로 |
| `GET /api/workspace` | 1 채택됨 v1 · 2 뼈대 생성됨 · 3 열림 |

## 같이 고친 것

`WorkspaceHome` 이 `useEffect` 를 이른 반환 **뒤에** 불렀다. 프로젝트가 0개에서 1개로 바뀌는
순간(첫 등록) 훅 순서가 달라져 React가 터진다. 훅을 반환 위로 올렸다.

`buildContract.ts` 는 **타입만** 가져온다. 커널에서 값을 하나라도 끌어오면 `node:fs` 를 쓰는 커널
묶음이 브라우저 묶음에 들어온다 — 뼈대 파일 이름과 설명은 서버가 붙여 내려준다.
