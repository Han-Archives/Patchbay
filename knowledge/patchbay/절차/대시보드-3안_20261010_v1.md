# 대시보드 3안 · 대화 패널 통합

- 요청: 제시한 배치안 3번으로 재구성하고 대화창까지 통일된 느낌으로 배치.
- 반영: 중앙에 큰 아키텍처·프로세스 전환 패널, 보조 열에 지식 그래프·문서 호출·확인할 사항. 최근 작업은 아래 배치. 지표·시험·요구사항·실행 노드는 접힌 상세 현황으로 정리.
- 대화: 오른쪽 진행바와 대화창을 같은 카드·배경·테두리·여백으로 묶음. 기본 대화 열기, 최소화·복원·닫기 지원. 모바일에서 고정 오버레이 대신 본문 아래 배치.
- 검증: 형검사·빌드 통과. 관련 대시보드·작업 공간·대화 테스트 41개 통과. Chrome 샘플 데이터로 1600px·1024px·390px 검증: 아키텍처 렌더링, 프로세스 전환, 상세 현황 펼치기, 대화 최소화·복원, 모바일 본문 표시와 가로 넘침 없음, 브라우저 오류 없음. 실제 프로젝트 LLM 호출은 하지 않음.
