# 대화 전송 서버 연결 복구

작성일: 2026-10-16.

## 원인과 조치

사용자가 Send 또는 Record를 누르면 입력창 위에 Failed to fetch가 표시된다고 보고했다. 로컬 4318 포트의 리스너가 없고 실제 연결 요청도 실패해 Patchbay 서버 중단을 확인했다. 서버가 종료된 계기는 확인되지 않았다.

기존 workspace를 사용하는 서버를 127.0.0.1:4318에서 복구했다. RoomPanel의 전송·중지 요청에서 연결 오류를 한국어 안내로 바꾸었다. 실패 시 입력을 지우지 않고, 자동 재전송하지 않는다. 성공 응답을 받은 뒤 입력을 비우는 기존 동작을 유지한다.

## 검증

Flow 형검사·클라이언트·서버 빌드와 roomHost·roomExecution 시험 26개 통과. 실제 서버 /api/session 응답 200 확인. 별도 임시 작업 공간과 모의 모델을 사용하는 Chrome 검증으로 Record·Send의 네트워크 차단 시 입력 보존과 안내, 복구 후 Record 저장·모델 미호출, Send 저장·모델 한 번 호출·응답 표시와 오류 해제를 확인했다. 실제 사용자의 요구사항이나 모델을 임의로 재전송하지 않았다.
