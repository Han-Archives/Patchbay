# 공개 push 전 비밀 검사 구현 · 2026-10-29

사용자 요청: 공개 저장소로 push하기 전에 `.env`·인증 파일 경로와 대표 API 키·토큰·웹훅 형식을 실제 값 노출 없이 자동 차단한다.

## 반영

- `app/hooks/pre-push`: `.env`와 인증서·개인 키·클라우드 자격 증명 경로를 차단한다. `.env.example`·`.env.sample`·`.env.template`은 템플릿으로 허용한다.
- AWS·GitHub·OpenAI/Anthropic·xAI·Slack·Google·Stripe·Discord·Telegram의 명백한 키·토큰·웹훅 형식과 개인 키 머리글을 좁은 정규식으로 검사한다.
- 로그에는 탐지 종류·커밋 ID·파일 경로만 표시하고 실제 일치 값은 출력하지 않는다.
- push 끝 커밋만 보지 않고 원격 커밋 이후 새로 올라가는 모든 커밋을 검사한다. 중간 커밋에서 비밀을 넣었다가 지운 경우도 공개 이력에 남으므로 차단한다.
- 기존 공개 시작 이력·`private-names` 검사는 유지하고 같은 새 커밋 범위에 적용한다.

## 확인

- `sh -n app/hooks/pre-push` 통과.
- 대상 시험 `publicPushGuard.test.ts`: 4건 통과. 깨끗한 트리·템플릿 허용, 위험 경로, 대표 값 형식, 뒤 커밋에서 지운 비밀을 확인했다.
- `pnpm --dir app build` 통과.
- `CHOKIDAR_USEPOLLING=1 pnpm --dir app test`: 174개 파일 통과, 1개 건너뜀. 시험 1,352개 통과, 3개 건너뜀.

커밋·push·서버 재시작은 하지 않았다. 결과는 수리 검토 대상으로 넘긴다.
