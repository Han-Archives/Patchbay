# 할일 안내 제거 · 6건 표시

요청: 할일 제목 아래 ‘위에서 아래로 진행’ 문구 제거, 사용자 요구사항이나 실행 중 생긴 작업을 목록에 추가하며 6건 이후 스크롤로 확인.

반영: 안내 문구를 없애고 미완료 목록 높이를 480px(기본 행 80px × 6)로 제한했다. 데이터는 자르지 않고 전부 저장·렌더하며 7건부터 내부 스크롤한다. 긴 제목은 두 줄까지 표시하고 전체 제목은 툴팁으로 확인한다. 상세를 펼치면 목록 안에서 스크롤한다. 스크롤에 가려지지 않도록 … 메뉴는 화면 위에 따로 표시한다.

사용자의 + 등록과 Agent가 새로 정리한 작업은 기존 목록 하단에 추가된다. Agent 작업 지침에 신규 요구사항·미해결 오류·후속 작업의 중복 확인과 하단 추가, 기존 목록 유지, 저장 개수 무제한을 명시했다. 화면은 기존 3초 조회로 새 항목을 반영한다.

검증: Flow 형검사·빌드, 대화방·할일 동작 시험 20개 통과. 실제 빌드 브라우저에서 안내 제거, 6행 높이, 초과 스크롤, 새 후속 작업 추가 반영, 스크롤 끝 메뉴의 완료 처리, 기존 추가·드래그·대화·불빛·보관 및 모바일 조작 통과. 예시 데이터는 임시 작업 공간에서만 사용했다.
