# 로고와 작업 표 정렬

작성일: 2026-10-15.

## 반영

- 데스크톱 대시보드 왼쪽 레일의 Patchbay 아이콘을 26px에서 40px로 키우고 프로젝트명과 중심 높이를 맞췄다.
- 작업 사항 표의 번호·항목명·상태·설명·태그·실행 열 사이에 세로 구분선을 추가했다. 기존 행 구분선은 유지한다.
- 상태 표시의 최소 너비를 없애고 글자와 좌우 6px 여백에 맞췄다. ‘대기 중’은 약 46px로 표시된다.

## 검증

Flow 형검사·클라이언트 및 서버 빌드 통과. Chrome 임시 데이터로 1440×900, 1280×800, 1200×800, 1024×768에서 아이콘 40px, 제목과 중심 차이 0.05px, 열 구분선, 상태 표시 너비, 메인 스크롤 없음을 확인했다. 작업 행 펼치기와 390×844의 모바일 탐색도 확인했다.
